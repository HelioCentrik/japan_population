Data Dictionary

All tables, views, and fields in japan_population.duckdb. The database is a star schema centered on f_census — one row per prefecture × year × age group × sex combination. Four dimension tables normalize the key attributes. Three additional fact tables (TFR, migration, IPSS projections) share the same dimensional spine. All app queries run through pre-joined views.

Query surface rule: Never query fact or dimension tables directly in app code. All reads go through the pre-joined views — v_census for census data, v_map_metrics for choropleth map data. The views exist to enforce this contract.

Pre-Joined Query Surfaces

Views

Views are the app's contract layer — they pre-join dimension tables so callbacks never re-join manually. Each view has a specific purpose; using the wrong one for a given task is a documented anti-pattern.

v_census
Grain: one row per year × area_estat × age_group × sex. All census years 1920–2020.
VIEW PRIMARY QUERY SURFACE
Use this for: all population queries, pyramid data, time series, KPI cards. Always filter area_level = 2 (prefecture) and age_scheme = 'scheme_a' for derived metrics. Never re-join dimension tables manually — they're already here.
FieldTypeDescription
year PKintCensus year. Begins 1920.
area_estat PKstr5-digit e-Stat area code, zero-padded. 01000 = Hokkaido, 13000 = Tokyo, 00000 = national aggregate. Join key for geometry.
prefecture_namestrEnglish prefecture name.
prefecture_name_jastrJapanese prefecture name, e.g. 北海道, 東京都.
area_levelintAlways filter area_level = 2 for prefecture queries. 1 = national aggregate (00000). 2 = prefecture. Omitting this filter double-counts by including the national row.
parent_estatstrParent area code. All prefectures point to 00000.
age_group PKstrAge band label, e.g. 0–4 years old. The Total row is a pre-stored aggregate — never use it in arithmetic; sum individual bands instead.
age_startintLower bound of the age band, inclusive.
age_endint / nullUpper bound, inclusive. NULL for open-ended terminal bands (e.g. 85+). Filter age_start >= 65 — not age_end — to safely capture all 65+ regardless of terminal band.
is_open_endedboolTrue if the band has no upper bound.
age_scheme PKstrscheme_a = standard 5-year bands, 0–4 through 85+. scheme_b = kazoedoshi offset bands (1–5 through 86+), 1945 only. Always use scheme_a for derived metrics.
sex PKstrtotal, male, or female. Filter sex = 'total' for all aggregate metrics.
sex_jastrJapanese label: 総数, 男, 女.
populationintHeadcount for this combination of year / area / age band / sex.
v_map_metrics
Grain: one row per area_estat × year. 47 prefectures per year. No national aggregate row.

Map data comes exclusively from here. Pre-aggregated with period deltas. Do not query v_census for map data — it defeats the view's purpose and re-derives what's already computed.

f_migration
Grain: one row per area_estat × census_year. 47 rows per census year.
FACT
Source: e-Stat 住民基本台帳人口移動報告. Stitched from 8 overlapping datasets (1982–2025). No prefecture-level data exists prior to 1982 — census years 1960–1980 are genuinely missing. Rollup window: census year Y = Σ annual net migration for (Y−4) through Y inclusive. 1985 is partial (4 of 5 years; data begins 1982).
FieldTypeDescription
area_estat FKstr→ d_prefectures. PK component.
census_year FKint→ d_years. PK component.
net_migrationintSum of annual 転入超過数 for the 5-year window. Negative = net outflow. NULL for 1960–1980 — do not infer zero.
f_projections
Grain: area_estat × projection_year × age_group_id × sex_id. 17,766 rows.
FACT
Source: IPSS 日本の地域別将来推計人口（平成30（2018）年推計）. Coverage: 2015–2045, 5-year intervals, 47 prefectures, 18 age bands (scheme_a), 3 sex values. IPSS publishes 85–89 and 90+ separately; both are summed into the 85+ group to match d_age_groups. ETL is idempotent (DROP TABLE IF EXISTS before write).

sex_id FKint→ d_sex
populationintProjected headcount. No NULLs.
f_national_projections
Grain: one row per projection_year × variant. 153 rows (51 years × 3 variants). Standalone — no FK relationships.
FACT
Source: IPSS 2017 national projections (平成29年推計), Tables 1-1 (medium), 1-2 (high), 1-3 (low). Coverage: 2015–2065, annual. Variants differ only in fertility assumption — mortality is held at medium in all three. Use high as upper bound and low as lower bound for the confidence band visualization. All three variants share the same 2015 starting population (~127.1M).
FieldTypeDescription

variantvarchar'medium', 'high', or 'low'.
total_populationbigintProjected national headcount (raw, not thousands).
pop_0_14bigintPopulation aged 0–14.
pop_15_64bigintPopulation aged 15–64.
pop_65_plusbigintPopulation aged 65 and over.
